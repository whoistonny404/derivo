# Welcome to your Expo app 👋

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), a limited sandbox for trying out app development with Expo

You can start developing by editing the files inside the **src/app** directory. This project uses [file-based routing](https://docs.expo.dev/router/introduction).

## Android APK

Build a release APK with `npm run build:apk`. The script first clears only project-local generated caches and build outputs, then runs Expo prebuild to apply the Android floating-overlay plugin and assembles the APK. It does not clear the shared Gradle cache. By default it builds for ARM64; run `npm run build:apk -- --all-architectures` to include all configured Android architectures.

The demo bot requires Android's **Display over other apps** permission to show its floating control. Grant it when prompted in Android Settings. The dashboard subscribes to public Deriv tick data over its WebSocket API; the market list is limited to the indices shown in the supplied screenshot. Set `EXPO_PUBLIC_DERIV_APP_ID` to your registered Deriv application ID when building for release. The default ID is for testing only.

The account session and bot remain local demo behavior. The app does not authorize a Deriv account or place trades. Once-daily email verification is deferred until an HTTPS verification backend is available; the app does not accept or store an API token as a substitute.

## Get a fresh project

When you're ready, run:

```bash
npm run reset-project
```

This command will move the starter code to the **example** directory and create a blank **src/app** directory where you can start developing.
